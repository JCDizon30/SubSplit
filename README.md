# SubSplit

Decentralized subscription-sharing escrow built on Stellar Soroban.

---

## Problem

Students and young professionals manually collect shared subscription payments every month, causing late payments, ghost members, and unfair costs for the account owner.

## Solution

SubSplit uses Stellar Soroban smart contracts to automate subscription pool payments, member management, and unpaid member revocation using low-cost USDC transactions.
